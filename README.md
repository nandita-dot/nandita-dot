### 🛣️ RoadSafe Bengaluru

**IBM National Hackathon 2026 — Top 10 Team**

A road-safety decision-support platform that turns public crash data into actionable decisions for Bengaluru's **53 traffic-police stations**.

**Built with:** Python · XGBoost · scikit-learn · JavaScript · OpenStreetMap · Leaflet

**What makes it interesting:**

* Risk scoring for every traffic-police station
* 2026–28 road-death forecasting
* Explainable ML predictions
* Evidence-backed intervention recommendations
* Agent-based traffic simulation
* "Do nothing" vs intervention scenario comparison
* Browser-based deployment with no backend requirement

🔗 **[Explore the project →](https://github.com/IAteNoodles/IBM2K26)**

### 🧠 Customer Feedback Intelligence System

An NLP pipeline that moves beyond simple sentiment analysis to understand **what customers are discussing, how those topics change, and which issues deserve attention**.

**Built with:** Python · BERTopic · VADER · scikit-learn · Pandas · Streamlit · Plotly

**Pipeline:**

`Reviews → Preprocessing → Sentiment + Topics → Temporal Analysis → Drift Detection → Severity → Recommendations`

Features include:

* Temporal topic modeling
* Sentiment analysis
* Topic drift detection
* SKU-level intelligence
* Issue severity scoring
* Issue prioritization
* Corrective recommendations
* Explainable business insights
* Interactive Streamlit dashboard

🔗 **[Explore the project →](https://github.com/nandita-dot/customer-feedback-intelligence-with-sku)**

### 🎬 MovieVerse

A production-oriented movie ticket booking backend focused on **database correctness and transactional booking**, not just CRUD.

**Built with:** Java · Spring Boot · Spring Data JPA · Hibernate · MySQL · Docker

Highlights:

* Layered Controller → Service → Repository architecture
* Relational database design
* Transaction-based seat booking
* Database constraint preventing duplicate seat reservations
* REST APIs
* Dockerized Spring Boot + MySQL deployment

🔗 **[Explore the project →](https://github.com/nandita-dot/MovieVerse-)**

### 🤖 AI Research Agent

A tool-calling AI agent that can decide when it needs external information, search the web, and produce structured, source-aware responses.

**Built with:** Python · LangChain · Google Gemini · DuckDuckGo · Pydantic

The project explores the difference between a basic LLM application and an **agent capable of interacting with external tools**.
